Configuración inicial de Firebase

1

Crea el proyecto Firebase

Ve a console.firebase.google.com → "Crear proyecto" → nombre cualquiera → "Crear".

2

Activa Firestore

Build → Firestore Database → Crear base de datos → Modo de prueba → us-east1 → Listo

3

Obtén tu configuración

⚙️ Configuración → General → Tus apps → icono </> → registra la app → copia el objeto:

{ apiKey: "...", authDomain: "...", projectId: "...", storageBucket: "...", messagingSenderId: "...", appId: "..." }
4

Pega la configuración aquí

Esta configuración se guarda en tu navegador. Solo una vez.
